# 科技感工作台界面

用户要求去掉杂志感，换成科技感专业工作台。产品步骤、数据和导出不变。

## Direction contract

THESIS: 校对台是亮色商务工作台，不是夜里的深色外壳，也不是一页暖纸。拒绝巨型标题和杂志衬线。
OWN-WORLD: 白底工作面，浅灰页面 `#eef1f4`，深灰字 `#1c2430`，商务蓝 `#1b4f86` 只用于当前步骤和主按钮。中文只用 Noto Sans SC。
STORY: 用户从说明走到大纲、属性、文字、编辑和配图，每一步都在同一条紧凑步骤条上。
FIRST VIEWPORT: 顶栏是产品名和步骤，其下是状态条，主区是带边框的工作面，主按钮在表单末尾。
FORM: 用户指定的工作台，不经过概念骰子。种子不适用。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## 边界

界面皮肤和幻灯片内容分开。画布、模板缩略图和导出颜色仍用模板自己的纸色与墨色，不把用户的幻灯片改成黑底。
