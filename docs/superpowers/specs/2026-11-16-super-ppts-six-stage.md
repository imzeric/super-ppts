# 六步旅程

本文件取代四步导航。原生可编辑导出和接口设置仍然有效。

1. 首页是一张大纸，多行输入生成说明。产品层不设字数上限，也不截断。单次传输超过 100 万字时拒绝并说明，已保存的文本保持原样。
2. Markdown 编辑器可改、可预览、可保存、可重新加载。优化仍是候选。解析上限是 40 张，超出部分留在原文里并给出行号，不静默删除。
3. 选择 16:9、4:3 或 16:10。模板库有「不使用模板」「纪要」「讲义」「夜场」，都是仓库内置。不选模板可以确认。改比例会等比缩放已有占位。
4. 确认大纲和属性之后才生成每页文字。失败不假装成功。
5. 编辑器左侧是缩略图，中间是画布，右侧是属性和绘图来源。可改文字、添加多种占位。上下方向键切换幻灯片，Ctrl/⌘+S 保存。未保存时离开页面会提示。
6. 按占位生成 PNG、SVG 或 PowerPoint 可编辑对象，然后导出。

来源和输出分开。Mermaid 只支持 `flowchart`/`graph` 的 TD、TB、LR，以及 `A[文字]`、`A(文字)`、`A((文字))`、`A{文字}` 和 `-->`。AntV 只接受 G6 风格的 JSON：`nodes` 与 `edges`，不执行脚本。编辑器里 Mermaid 用官方库渲染，AntV 用 `@antv/g6` 渲染。PNG 和 SVG 由同一份节点数据画出。原生输出写成形状和带端点绑定的连接线，或带工作簿的图表。模型插图只能是 PNG。SVG 会去掉 script、foreignObject 和外部链接。

不在本轮：任意 Mermaid 图种、AntV 图表库 G2、任意 PPT 模板导入、桌面版 PowerPoint 验收、真实付费接口调用。
